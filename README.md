# Project AeroParse: Rocket Dynamics Data Pipeline
**Completed by** EngineeringArmor  (Freshman ECHS Scholar)
##Target Focus:**  Aerospace Engineering & Computational Modeling


## 📊 Project Overview
This project bridges the gap between aerodynamic physical modeling and programmatic data analysis. Using **OpenRocket**, a stable flight configuration was designed for a single-stage rocket utilizing an Estes C6-5 motor.


Telemetry data was exported to a CSV format, and a custom **Python** pipeline utilizing **Pandas** and **Matplotlib** was developed to parse the flight dataset, compute kinematic metrics, and output a high-fidelity flight dynamics profile graph.


## 📈 Engineering Performance Data
* **Peak Flight Velocity** 48.0 m/s
* **Maximum Altitude (Apogee):** ~58.0 meters
* **Peak Structural Acceleration:** 103.0 m/s sq


## 🛠 Softare & Tools Utilized
* **OpenRocket IDE:** Aerodynamic stability configuration and numerical physics engine simulation.
* ***VS Code** Integrated development enviornment for script deployment.
* **Python 3:** Data structure parsing. string normalization, and telemetry plotting.
